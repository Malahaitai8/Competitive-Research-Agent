# 侧栏返回主页按钮设计

## 目标

在左侧栏底部增加“返回主页”按钮，让用户从任务结果、执行进度、失败页或配置流程快速回到欢迎页。

## 方案比较

1. **侧栏底部固定按钮（采用）**：入口稳定，不与历史任务混在一起；桌面、折叠侧栏和移动抽屉均可复用。
2. 顶部品牌区可点击：界面更简洁，但可发现性弱，也不符合用户明确要求的“按钮”。
3. 结果栏顶部返回按钮：只覆盖结果页，无法统一服务配置页和执行页。

## 交互

- 按钮使用线性主页图标和“返回主页”文案。
- 点击后清除当前选中的任务和 URL 中的 `task` 参数，切换到 `welcome` 视图。
- 不删除历史记录，不取消或中止后台调研。
- 移动端点击后同时关闭侧栏抽屉。
- 侧栏折叠时仅保留主页图标，并通过 `aria-label` 和 `title` 提供含义。

## 视觉

- 位于侧栏底部独立区域，与历史列表通过上边框分隔。
- 使用透明背景、中性文字和现有灰蓝绿悬停/焦点态。
- 不使用实心主按钮样式，避免与“新建调研”竞争视觉层级。

## 验证

- 从欢迎页、配置页、执行页和结果页点击均回到欢迎页。
- URL 中当前任务 ID 被清除。
- 后台任务和历史记录保持不变。
- 桌面折叠侧栏与移动端抽屉中入口可用。
- 运行布局回归与 JavaScript 语法检查。
